## Fixed Issues

### CR-01: PWA manifest conflates two distinct icon purposes in a single entry

**Files modified:** `apps/frontend/vite.config.ts`
**Commit:** 4e66dd5
**Applied fix:** Replaced the combined `purpose: 'any maskable'` entry (which incorrectly pointed at the un-padded `pwa-512x512.png`) with four separate entries: `pwa-64x64.png` (no purpose), `pwa-192x192.png` (no purpose), `pwa-512x512.png` with `purpose: 'any'`, and `maskable-icon-512x512.png` with `purpose: 'maskable'`. The maskable entry now correctly points at the padded asset generated by pwa-assets-generator. The missing pwa-64x64.png entry was also added.

### WR-01: Logo SVG invisible in dark-mode contexts — hardcoded white fill

**Files modified:** `apps/frontend/public/logo.svg`, `apps/frontend/public/favicon.svg`
**Commit:** 1cb06c1
**Applied fix:** Added a `<style>` block with `@media (prefers-color-scheme: dark) { .card-bg { fill: #1e1b4b; } }` inside both SVG files, and added `class="card-bg"` to the card background rect element. The `fill="#ffffff"` attribute is retained as the light-mode default. favicon.svg received the identical change since it is a copy of logo.svg.

### WR-02: Mobile drawer nav violates ARIA while visually hidden (focusable children remain in tab order)

**Files modified:** `apps/frontend/src/components/AppShell.tsx`
**Commit:** 94bf63d
**Applied fix:** Added `{...(!drawerOpen && { inert: '' })}` spread to the `#mobile-nav-drawer` div, immediately after the `aria-hidden` prop. When the drawer is closed, the `inert` attribute is set to `''`, removing all interactive children from the keyboard tab order and AT interaction.

### WR-03: `currentLabel` computed with double `navItems.find()` call — also silently falls back to hardcoded string 'Kartex'

**Files modified:** `apps/frontend/src/components/AppShell.tsx`, `apps/frontend/src/locales/en.json`, `apps/frontend/src/locales/de.json`
**Commit:** c589ce5
**Applied fix:** Extracted the `navItems.find()` result into a `matchedItem` variable so the predicate runs only once. Replaced the hardcoded `'Kartex'` fallback string with `t('nav.home')`. Added `"home": "Kartex"` to the `nav` section in both `en.json` and `de.json`.

### WR-04: Test SHELL-02b's backdrop selector is overly fragile and will break if class order changes

**Files modified:** `apps/frontend/src/components/AppShell.tsx`, `apps/frontend/src/components/__tests__/AppShell.test.tsx`
**Commit:** b9f9f48
**Applied fix:** Added `data-testid="mobile-backdrop"` to the backdrop `<div>` in AppShell.tsx. Updated the SHELL-02b test to use `screen.getByTestId('mobile-backdrop')` instead of the compound CSS selector `document.querySelector('[aria-hidden="true"].fixed.inset-0')`. The stale `expect(backdrop).not.toBeNull()` guard was removed since `getByTestId` throws automatically if the element is absent, giving a cleaner failure message.
