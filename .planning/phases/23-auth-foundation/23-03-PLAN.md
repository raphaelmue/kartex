## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser → DELETE /users/:id | Authenticated admin performs an irreversible hard delete; protected by requireAdmin |
| backend → filesystem | Media files unlinked from the local volume during delete |
| backend → database | Multi-table cascade delete must be atomic |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Tampering / IDOR | DELETE /users/:id | mitigate | requireAdmin middleware gates the route; target existence checked before delete; only ADMIN role reaches the handler |
| T-23-04 | Elevation of privilege | self-delete | mitigate | `id === authenticatedUserId` guard returns 400 (SELF_DELETE) before any deletion |
| T-23-05 | Denial of service | last-admin lockout | mitigate | `adminCount <= 1 && target.role === 'ADMIN'` guard returns 400 (LAST_ADMIN) |
| T-23-06 | Integrity | partial delete mid-cascade | mitigate | All row deletes wrapped in a single `prisma.$transaction` array — atomic; media file unlink is best-effort and intentionally outside the transaction (D-07) |
| T-23-07 | Integrity | FK violation on user.delete | mitigate | Explicit ordered delete (incl. InviteCode.usedById which has no onDelete) clears all references before user.delete; deckIds pre-computed (Pitfall 2) |
| T-23-SC | Tampering | npm/yarn installs | accept | This plan installs no new packages |
</threat_model>
