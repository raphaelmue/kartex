<objective>
Gap closure for Phase 8 UAT issues (Tests 6 & 7): replace the h3 section-grouped card list in DeckDetailPage with a flat sortable Table and a tag filter bar on top.

**Root cause of UAT issue:** The groupCardsByFirstTag-based section layout causes cards with the same tags in different stored order to land in different sections (e.g., card with ['tag1','tag2'] → section 'tag1'; card with ['tag2','tag1'] → section 'tag2'). The user also prefers a flat table + filter bar UX over section headers.

**Fix approach:** Replace the grouped rendering with:
1. A tag filter bar (chips/buttons, one per unique tag, sorted A–Z) above the card table
2. A flat Table showing all cards by default
3. When a tag chip is selected, only cards containing that tag are shown
4. With this approach, a card with ['tag1','tag2'] naturally appears under either tag filter — no deduplication problem.

groupCardsByFirstTag.ts is retained unchanged — STUDY-04a/04b tests continue to pass. Only the DeckDetailPage rendering and STUDY-04c test change.
</objective>
