<objective>
Implement the backend half of LIB-01: per-user isActive state for library decks.

This plan adds DeckShare.isActive to the Prisma schema, creates the hand-written SQL migration, exports UpdateLibrarySchema from shared, fixes GET /api/decks to return DeckShare.isActive for shared deck items, adds the new PATCH /api/decks/:id/library endpoint, and fixes GET /api/study/due to filter shared decks by DeckShare.isActive instead of Deck.isActive.

Purpose: Without this plan, toggling a library deck is impossible — there is no column to store per-user state and no endpoint to update it. The study filter bug means shared decks always enter the queue regardless of recipient preference.

Output: Schema migration, shared schema export, three route changes in decks.ts + study.ts.
</objective>

| JWT middleware → route handler | userId extracted from validated JWT — trusted within the request context |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Spoofing | PATCH /api/decks/:id/library | mitigate | JWT auth middleware already applied on all /api/* routes; userId from `c.get('userId')` not from request body |
| T-18-02 | Tampering | DeckShare.isActive update | mitigate | `findUnique` on `deckId_sharedWithUserId` before `update` — caller can only update their own share row; owner blocked by null share guard (403) |
| T-18-03 | Elevation of privilege | PATCH attempts by deck owner | mitigate | Owner has no DeckShare row for their own deck — `findUnique` returns null → 403 returned before any DB write |
| T-18-04 | Tampering | isActive value injection | mitigate | `UpdateLibrarySchema` uses `z.boolean()` — non-boolean values rejected with 400 before DB update |
| T-18-05 | Information Disclosure | 403 response on missing share | accept | 403 reveals that either the user is the owner or has no share row, but not which condition; consistent with existing REST patterns |
| T-18-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan — no package legitimacy gate required |
