## Component Inventory

Two UI surfaces are introduced or modified in this phase.

### Surface 1 — InviteTokensSection (AdminPage modification)

Replaces `InviteCodesSection` (removed per D-01). Placed in the same vertical position within AdminPage.

**Structure:**

```
<Card>
  <CardHeader>
    <CardTitle>   — "Email Invitations"
    <CardDescription>  — "Send one-time invitation links to new users."
  <CardContent>
    <div className="flex gap-2 mb-6">   — email input + send button row
      <Input type="email" placeholder="Email address" className="flex-1" />
      <Button type="button">Send Invite</Button>   — primary variant
    </div>
    <Table>
      <TableHeader>
        Email | Sent | Expires | (revoke col, no label)
      <TableBody>
        row: email | sent-date | expires-date | <Button size="icon" variant="ghost" className="text-destructive hover:text-destructive">
```

**States:**

| State | Behavior |
|-------|----------|
| Idle | Input empty, "Send Invite" enabled |
| Submitting | "Send Invite" disabled, Loader2 spinner inside button (`h-4 w-4 animate-spin`) |
| Send success | `toast.success(t('admin.inviteSentSuccess', { email }))` — table refreshes |
| Send error — SMTP not configured | `toast.error(t('admin.inviteSMTPMissing'))` |
| Send error — general | `toast.error(t('common.somethingWrong'))` |
| Empty pending list | Table body shows single row: `<TableCell colSpan={4} className="text-center text-sm text-muted-foreground">` — "No pending invitations." |
| Revoke — in progress | Row revoke button disabled, shows Loader2 spinner |
| Revoke success | `toast.success(t('admin.inviteRevokeSuccess'))` — table refreshes |

**Revoke interaction:** Direct icon button — no confirmation dialog. The action is low-risk (no user data is lost; the admin can re-issue an invitation). Use `Trash2` icon from lucide-react, size 16px (`h-4 w-4`). Button: `size="icon" variant="ghost" className="text-destructive hover:text-destructive"`.

**Date formatting:** Display sent/expires dates as locale-aware short date strings (e.g., `new Date(d).toLocaleDateString()`). No time component shown.

### Surface 2 — InviteRegisterPage (new public page)

Route: `/invite/:token` — outside `ProtectedRoute` wrapper.

**Layout:** Centered full-screen, same as RegisterPage: `min-h-screen flex items-center justify-center bg-background`.

**Card:** `w-[400px] max-w-[calc(100vw-32px)]` — direct inheritance from RegisterPage.

**States (three distinct render modes):**

**State A — Loading (token validation in progress):**
```
<Card>
  <CardContent className="flex items-center justify-center py-12">
    <Loader2 className="h-6 w-6 animate-spin text-muted-foreground" />
```
Shown while `GET /api/invites/:token` is in flight. No skeleton; spinner is sufficient for a single API call.

**State B — Error (token invalid, expired, or already used):**
```
<Card>
  <CardHeader>
    <CardTitle>   — "Unable to register"
  <CardContent>
    <p className="text-sm text-muted-foreground">   — error message (one of three; see Copywriting)
  <CardFooter>
    <Link to="/login">   — "Back to sign in"
```
No redirect. Rendered inline per D-09. All three error codes map to distinct copy per D-10.

**State C — Form (valid token):**
```
<Card>
  <CardHeader>
    <CardTitle>   — "Create your account"
    <CardDescription>   — "You've been invited to Kartex. Enter your details below."
  <CardContent>
    <Form>
      <FormField name="email">   — disabled Input, pre-filled from API response
      <FormField name="username">
      <FormField name="password">
      <FormField name="confirmPassword">   — client-side only, not in RegisterSchema
      <Button type="submit" className="w-full mt-8">Create Account</Button>
  <CardFooter className="text-sm text-muted-foreground">
    "Already have an account?" <Link to="/login">Sign in</Link>
```

**Field interaction rules:**
- Email: `<Input type="email" disabled {...field} />` — visually greyed (`opacity-50` from shadcn disabled state), not editable. Value set via `form.setValue('email', data.email)` after token validation resolves.
- Confirm password: not part of `RegisterSchema` in shared package. Validate `password === confirmPassword` in the form's `onSubmit` handler before calling the API. Show error via `form.setError('confirmPassword', { message: t('auth.passwordMismatch') })`.
- Submit button: disabled + Loader2 spinner while `isSubmitting`. Label changes: "Create Account" → "Creating account…" (`t('auth.creatingAccount')`).

**Post-submit routing:** On success (200), navigate to `/login` with `{ state: { registered: true } }` — identical to the old RegisterPage pattern.

**Field error messages:**
- Username taken (409): `form.setError('username', { message: t('auth.usernameTaken') })` — already in i18n.
- Confirm password mismatch: `form.setError('confirmPassword', { message: t('auth.passwordMismatch') })`.
- Other server errors: `toast.error(t('common.somethingWrong'))`.
