| Boundary | Description |
|----------|-------------|
| card content → KartexRenderer | Card content string (stored in DB) flows through remark/rehype pipeline; malformed math should not crash the renderer |
| rehype-katex error path → DOM | KaTeX parse errors produce error HTML; no raw user input reaches dangerouslySetInnerHTML in this plan |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | rehype-katex error color | accept | errorColor is hardcoded to `hsl(0 84% 60%)` — no user control over rendering options |
| T-03-02 | Denial of Service | KaTeX parse failure | mitigate | throwOnError: false passed to rehypeKatex — malformed math renders as error text, does not crash the React tree |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | Package Legitimacy Audit completed in RESEARCH.md — katex, remark-math, rehype-katex, rehype-highlight, highlight.js all [OK] verified |
