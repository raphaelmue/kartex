| DashboardPage state → StatsSummaryPanel | Untrusted/absent data (null summary) crosses into a pure display component that must render safe empty states |

| T-15-02 | Tampering (data integrity) | StatsSummaryPanel render | mitigate | Component checks `retentionRate === null` and `difficultyBreakdown === null` explicitly and renders "No data yet" — never fabricates 0% from a null |
| T-15-SC | Tampering | npm/pip/cargo installs | accept | No package installs — all shadcn components (Badge, Table) already present per UI-SPEC Registry Safety; RESEARCH.md confirms zero new dependencies |
