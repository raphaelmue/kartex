| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-15-01 | Information Disclosure | stats.ts Prisma queries | mitigate | userId always from `c.get('userId')`; every query (and the nested `progress` select) carries `where: { userId }`; no userId read from params/body (V4 Access Control) |
