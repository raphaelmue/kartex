## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (`gap-1`, `px-1`) |
| sm | 8px | Compact element spacing (`gap-2`, `px-2`, `py-2`) |
| md | 16px | Default element spacing (`p-4`, `gap-4`) |
| lg | 24px | Section padding (`p-6`, `gap-6`) |
| xl | 32px | Layout gaps (`mb-8` = 32px) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (empty-state `py-16`) |

Exceptions:
- Touch targets: ⋮ menu trigger button uses `size="sm"` (h-8, 32px) — acceptable; DropdownMenu items add vertical padding to meet 44px tap area via Radix internal padding
- `AppShell` `<main>` uses `p-4` on mobile, `md:p-8` on desktop — this is the existing standard; do NOT change it (MOB-01 fix must not alter this)

> Source: existing codebase patterns in `AppShell.tsx`, `DecksPage.tsx`, `DashboardPage.tsx`.

## Interaction Contracts

### DECK-05 — Deck Card Footer Restructure

**Layout rule:** `CardFooter` must never overflow its card container at 375px or 1280px viewport.

**Structure (owned deck — `!deck.sharedByUsername`):**

```
CardFooter
├── Left group (mr-auto, flex items-center gap-2)
│   ├── Switch (active toggle)
│   └── <label> "Active"
├── Button size="sm" variant="default"  → "Study"
├── Button size="sm" variant="outline"  → "Open" (asChild Link)
└── DropdownMenu
    ├── Trigger: Button size="sm" variant="ghost" aria-label="More actions"
    │   └── MoreVertical icon (lucide-react, h-4 w-4)
    └── Content
        ├── DropdownMenuItem → "Edit" (calls openEdit)
        └── DropdownMenuItem variant destructive → "Delete" (opens AlertDialog)
```

**Structure (shared/library deck — `deck.sharedByUsername` is set):**

```
CardFooter
├── Button size="sm" variant="default"  → "Study"
└── Button size="sm" variant="outline"  → "Open" (asChild Link)
```
No ⋮ menu — no overflow risk. Per D-03.

**State removed:** `confirmDeleteId` state and all inline confirm JSX are deleted. Replaced by AlertDialog open state.

**AlertDialog content:**
- Title: "Delete deck?" (i18n key: `decks.deleteConfirmTitle`)
- Description: "This cannot be undone." (i18n key: `decks.deleteConfirmBody`)
- Cancel button: "Cancel" (i18n key: `common.cancel`)
- Confirm button: "Delete" — `variant="destructive"` (i18n key: `decks.deleteButton`)

**Icon:** `MoreVertical` from `lucide-react`. Size: `h-4 w-4` (matches `[&_svg]:size-4` Button rule). Aria-label: `t('decks.moreActions')`.

### MOB-01 — Mobile Overflow Fixes

**Fix 1 — StatsSummaryPanel per-deck table:**

Wrap the `<Table>` at line ~127 of `StatsSummaryPanel.tsx` in:

```tsx
<div className="overflow-x-auto">
  <Table>…</Table>
</div>
```

No other changes to `StatsSummaryPanel.tsx`.

**Fix 2 — AppShell `<main>` (conditional):**

Add `overflow-x-hidden` to `<main>` in `AppShell.tsx` only if a concrete horizontal overflow is observed during the audit. Current classes: `flex-1 overflow-y-auto bg-background p-4 md:p-8`. If added, result: `flex-1 overflow-y-auto overflow-x-hidden bg-background p-4 md:p-8`.

**Fix 3 — DashboardPage wrapper (conditional):**

`DashboardPage.tsx` already uses `max-w-2xl mx-auto px-4 py-8` and `overflow-x-auto` on its primary table. Apply only targeted fixes if additional overflow is observed during audit. Do not change the `px-4` padding — that is the correct mobile padding.

**Scope boundary:** Only touch `StatsSummaryPanel.tsx`, `AppShell.tsx` (if needed), and `DashboardPage.tsx` (if needed). Per D-06 — do NOT audit all 9 AppShell pages.

## Accessibility Contract

- DropdownMenu trigger button must have `aria-label={t('decks.moreActions')}` (icon-only button)
- AlertDialog uses Radix `AlertDialog.Title` and `AlertDialog.Description` — screen reader accessible by default
- Delete action in DropdownMenu: use `role="menuitem"` (Radix default) — no additional ARIA needed
- Mobile touch targets: DropdownMenu trigger at `size="sm"` (h-8 = 32px) — below 44px minimum; compensate by ensuring DropdownMenu item rows have `py-2` (32px row height + 16px padding = 48px effective tap area inside menu)
- Table scroll container: add `role="region"` and `aria-label={t('dashboard.stats.perDeckProgress')}` to the `overflow-x-auto` wrapper div in `StatsSummaryPanel.tsx`
