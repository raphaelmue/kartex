  <action>
    Audit the AppShell `<main>` element at line ~256. Its current className is:
      "flex-1 overflow-y-auto bg-background p-4 md:p-8"

    The mobile nav drawer is a fixed-position element (`fixed top-0 left-0 h-full w-60`) that slides in
    from the left using CSS translate. When the drawer is off-screen (-translate-x-full), its width can
    contribute to the scrollable content area in some browser engines, causing a horizontal scrollbar.

    Add `overflow-x-hidden` to the `<main>` className, resulting in:
      "flex-1 overflow-y-auto overflow-x-hidden bg-background p-4 md:p-8"

    This is consistent with the UI-SPEC §MOB-01 Fix 2 guidance (conditional add — apply because the
    fixed-position drawer is always in the DOM at -translate-x-full and browser engines differ on
    whether fixed children affect overflow). The fix is mechanical and does not affect any content
    layout — p-4 md:p-8 is preserved exactly.

    Do NOT modify any other class or element in AppShell.tsx.

    Per D-06 and UI-SPEC §MOB-01 Fix 2.
  </action>
