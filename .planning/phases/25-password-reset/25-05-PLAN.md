<action>
In `apps/frontend/src/pages/AdminPage.tsx`, make three edits:

Edit 1 — Extend the DropdownMenu import: the existing import at lines 26–28 imports `DropdownMenu, DropdownMenuContent, DropdownMenuItem, DropdownMenuTrigger`. Add `DropdownMenuSeparator` to this import list. This component is in `@/components/ui/dropdown-menu` and must be imported explicitly (Pitfall 8 in RESEARCH.md — it is not currently imported and will cause a compile error if omitted).

Edit 2 — Add `handleSendPasswordReset` function inside the `UsersSection` function body (place it after `handleDeleteUser`, before the `handleConfirmKeyDown` function):

`handleSendPasswordReset` is an async function taking `id: string` as its parameter. It:
1. Calls `api.post('/api/admin/users/' + id + '/reset-password', {})` (no request body needed — user is identified by the URL param).
2. If res.ok: calls `toast.success(t('admin.resetSentSuccess'))`.
3. If not ok: parses body JSON (with `.catch(() => ({}))`), reads the `error` string from the parsed body, then:
   - If error === 'NO_EMAIL': `toast.error(t('admin.resetNoEmail'))` (RESET-08, D-03)
   - If error === 'SMTP_NOT_CONFIGURED': `toast.error(t('admin.inviteSMTPMissing'))` (reuse existing key)
   - If error === 'SMTP_ERROR': `toast.error(t('admin.inviteSendError'))` (reuse existing key)
   - Otherwise: `toast.error(t('common.somethingWrong'))`
4. On catch: `toast.error(t('common.somethingWrong'))`.

Edit 3 — Replace the DropdownMenuContent block (lines 439–447) to add the reset item and separator:

The new DropdownMenuContent contains three children in this order (D-02 — menu item order):
1. A DropdownMenuItem that calls `void handleSendPasswordReset(u.id)` on click, with text `t('admin.sendPasswordReset')`. No destructive className — this is a neutral action.
2. A DropdownMenuSeparator (the component imported in Edit 1).
3. The existing DropdownMenuItem for delete: className `text-destructive focus:text-destructive`, onClick `() => setDeleteTargetId(u.id)`, text `t('admin.deleteUser')` — unchanged.

The DropdownMenuTrigger and its Button (aria-label, onPointerDown, onClick) remain unchanged.
</action>
