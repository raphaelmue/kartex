    ```typescript
    auth.patch('/me', authMiddleware, async (c) => {
      const body = UpdateStudyModeSchema.safeParse(await c.req.json())
      if (!body.success) {
        return c.json({ error: 'Validation failed.', details: body.error.flatten() }, 400)
      }

      const updated = await prisma.user.update({
        where: { id: userId },
        data: { studyMode: body.data.studyMode },
        select: { id: true, username: true, role: true, isActive: true, studyMode: true, createdAt: true },
      })

      return c.json(updated, 200)
    })
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PATCH /me body → DB | StudyMode input validated by UpdateStudyModeSchema enum; invalid values rejected with 400 |
| rate endpoint → CardProgress | multiplier comes from DB (server-controlled), never from client; client sends only cardId + rating |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03 | Elevation of Privilege | PATCH /me without auth | mitigate | `authMiddleware` applied inline as 2nd arg — not relying on global middleware which does not cover /api/auth/* routes |
| T-11-04 | Tampering | Client sending arbitrary studyMode | mitigate | `UpdateStudyModeSchema = z.object({ studyMode: StudyModeSchema })` — only 3 enum values accepted; any other string returns 400 |
| T-11-05 | Tampering | Client trying to inflate interval via studyMode=unknown | mitigate | `STUDY_MODE_MULTIPLIERS[x] ?? 1.0` — unknown mode falls back to 1.0 (normal); no amplification possible |
| T-11-06 | Tampering | Interval stored as multiplied value (SM2-03 violation) | mitigate | Upsert explicitly writes `interval: sm2.interval` — test and code review check confirm this invariant |
</threat_model>
