# Phase 30 — UI Design Contract

> Visual and interaction contract for Phase 30: Study Timers & Stats.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** This phase adds exactly two visible surfaces: (1) a new
> count-up elapsed timer in the study-session header for normal/SR/deck
> modes (exam mode is unchanged — D-01), and (2) two new blocks appended to
> the existing `StatsSummaryPanel.tsx` on the Dashboard — a per-deck
> average flip-time column and a "Recent Sessions" list (D-10). No new
> pages, no new routes, no new modals. All decisions below are either
> locked by `30-CONTEXT.md` (D-01 through D-12, cited inline) or resolved
> here under "Claude's Discretion" using direct codebase precedent — never
> invented from scratch.

| Component | Path | Usage in Phase 30 |
|-----------|------|--------------------|
| `SessionTimer` (new) | `apps/frontend/src/components/SessionTimer.tsx` | Count-up elapsed timer for normal/SR/deck study modes (D-01, D-02) |

| `Badge` | `@/components/ui/badge` | Multi-deck tags in a session row (`variant="secondary"`, matches existing due-count badge); "Incomplete" indicator (`variant="outline"`, **first use of this variant in the codebase** — see Color section rationale) |
| `Timer` (icon) | `lucide-react` | `SessionTimer`'s leading icon — same icon `ExamTimer.tsx` already uses |

**Claude's Discretion — resolved (ExamTimer extension vs. sibling component):**
`SessionTimer` is a **new sibling component**, not a mode-flag extension of
`ExamTimer`. Reading `ExamTimer.tsx` directly shows its color-shift logic
(`secondsLeft <= 10` → red/pulse, `<= 60` → orange) is fundamentally a
countdown-to-zero urgency signal with no count-up equivalent — grafting a
`direction: 'up' | 'down'` prop onto `ExamTimer` would require branching
nearly every line of its effect and color logic, producing a component
that is two timers wearing one name. A new `SessionTimer.tsx` instead
**copies** `ExamTimer`'s proven primitives verbatim (mm:ss formatting,
`role="timer"`, `aria-live="off"`, `text-sm font-mono tabular-nums` class
list, `Timer` icon) but drops the color-shift thresholds entirely (D-05's
visibility-pause behavior is the only new logic, and it has no analog in
`ExamTimer`). This keeps both components small, readable, and each
correct for its one job — consistent with the file-size and single-
responsibility conventions already established in this codebase (STATE.md
`08-03`/`08-03` extraction precedents).

## Interaction Contracts

### 1. Session elapsed timer (D-01, D-02, D-05)

**Placement:** Same top-bar slot `ExamTimer` currently occupies in
`SessionRunner` (`StudySessionPage.tsx` lines 124–141) — the
`flex items-center justify-between pt-4 sm:pt-6 pb-3 shrink-0` row,
right-aligned opposite "Leave Session".

```tsx
{mode === 'exam' && examDurationSeconds !== null ? (
  <ExamTimer
    durationSeconds={examDurationSeconds}
    onExpire={() => setExamExpired(true)}
  />
) : (
  <SessionTimer startedAt={startTime} />
)}
```

- **Exam mode is unchanged** (D-01) — `ExamTimer`'s existing countdown is
  the only timer shown; `SessionTimer` never renders alongside it.
- **Normal/SR/deck modes** (D-02) show `SessionTimer` in the exact slot
  `ExamTimer` would otherwise occupy — never both, never neither, for any
  non-exam mode.
- `startedAt` is the existing `startTime` state already present in
  `SessionRunner` (`const [startTime] = useState(() => Date.now())`,
  line 46) — no new state is needed to seed the timer's start point.
- **Visibility pause (D-05):** while `document.hidden` is true, the
  displayed mm:ss value stops incrementing; it resumes exactly where it
  left off when the tab becomes visible again. This is a **silent**
  pause — no "paused" badge, no dimming, no icon change. The elapsed
  number simply does not advance during hidden time. Do not add a visual
  paused-state affordance; none was requested and D-05 frames this as
  an accuracy fix (idle time never counted), not a user-facing status.

**Markup (mirrors `ExamTimer.tsx` structure, no color-shift):**

```tsx
<div
  className="flex items-center gap-1 text-sm font-mono tabular-nums text-foreground"
  role="timer"
  aria-live="off"
  aria-label={t('study.sessionElapsedAriaLabel', { time: `${mins}:${secs}` })}
>
  <Timer className="h-4 w-4" aria-hidden="true" />
  <span>{mins}:{secs}</span>
</div>
```

- No color-shift thresholds — always `text-foreground` regardless of
  elapsed duration (see Color section rationale).
- Same `role="timer"` / `aria-live="off"` a11y contract as `ExamTimer` —
  screen readers are not interrupted every second; the accessible name
  updates silently and can be queried on demand.

### 2. Per-deck average flip time (D-10, D-12)

**Placement:** New column appended to the **existing** per-deck `Table`
in `StatsSummaryPanel.tsx` (lines 128–178) — same table, same rows, one
more `TableHead`/`TableCell` pair. Do **not** create a second, separate
table for this data (D-12 says "per deck, like the existing perDeck
block" — it is a column, not a new section).

```tsx
<TableHead className="hidden sm:table-cell text-xs font-normal uppercase tracking-wide text-muted-foreground text-right">
  {t('dashboard.stats.avgFlipTimeColumn')}
</TableHead>
```

```tsx
<TableCell className="hidden sm:table-cell text-right">
  {d.avgThinkingTimeMs === null ? (
    <span className="text-sm text-muted-foreground">{t('dashboard.stats.noData')}</span>
  ) : (
    <span className="text-sm text-foreground">{(d.avgThinkingTimeMs / 1000).toFixed(1)}s</span>
  )}
</TableCell>
```

- Column placement: **last** column, after "In Learning" — append-only,
  do not reorder existing columns (`Deck` / `Due` / `Mastered` /
  `In Learning` stay in their current order and `hidden sm:table-cell`
  visibility rules).
- **Null-safe per row** (T-15-02 empty-state convention, extended to the
  row level): a deck with zero captured `thinkingTimeMs` values shows
  `t('dashboard.stats.noData')` in muted text for that cell — the same
  string already used for the global retention/difficulty empty states —
  **not** `0.0s` or a blank cell. Other decks in the same table that do
  have data still show their number; this is a per-row null, not an
  all-or-nothing table state.
- Format: seconds with one decimal (`3.4s`), not mm:ss — flip times are
  expected to be single-digit-to-low-double-digit seconds, so mm:ss would
  read as needless padding (`00:03`). This intentionally differs from the
  session timer's mm:ss format, which covers multi-minute durations.

### 3. Recent Sessions list (D-06, D-07, D-08, D-09, D-11)

**Placement:** New section appended **after** the per-deck table, inside
`StatsSummaryPanel.tsx`, using the identical section-heading + table
wrapper structure already used for "Per-Deck Progress":

```tsx
<div className="mt-6">
  <p className="text-sm font-semibold text-foreground mb-2">
    {t('dashboard.stats.recentSessions')}
  </p>
  <div className="overflow-x-auto" role="region" aria-label={t('dashboard.stats.recentSessions')}>
    <Table>
      <TableHeader>
        <TableRow>
          <TableHead className="text-xs font-normal uppercase tracking-wide text-muted-foreground">
            {t('dashboard.stats.sessionDateColumn')}
          </TableHead>
          <TableHead className="text-xs font-normal uppercase tracking-wide text-muted-foreground">
            {t('dashboard.stats.sessionDeckColumn')}
          </TableHead>
          <TableHead className="text-xs font-normal uppercase tracking-wide text-muted-foreground text-right">
            {t('dashboard.stats.sessionDurationColumn')}
          </TableHead>
          <TableHead className="hidden sm:table-cell text-xs font-normal uppercase tracking-wide text-muted-foreground text-right">
            {t('dashboard.stats.sessionCardsColumn')}
          </TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        {recentSessions.length === 0 ? (
          <TableRow>
            <TableCell colSpan={4} className="text-center text-sm text-muted-foreground py-6">
              {t('dashboard.stats.noSessionsYet')}
            </TableCell>
          </TableRow>
        ) : (
          recentSessions.map((s) => (
            <TableRow key={s.id}>
              <TableCell className="text-sm text-foreground">{formatDate(s.startedAt)}</TableCell>
              <TableCell>
                <div className="flex flex-wrap gap-1">
                  {s.deckTitles.map((title) => (
                    <Badge key={title} variant="secondary" className="text-xs">{title}</Badge>
                  ))}
                </div>
              </TableCell>
              <TableCell className="text-right text-sm text-foreground">
                {formatDuration(s.durationSeconds)}
                {!s.completed && (
                  <Badge variant="outline" className="ml-2 text-xs">
                    {t('dashboard.stats.incompleteSession')}
                  </Badge>
                )}
              </TableCell>
              <TableCell className="hidden sm:table-cell text-right text-sm text-foreground">
                {s.cardsReviewed}
              </TableCell>
            </TableRow>
          ))
        )}
      </TableBody>
    </Table>
  </div>
</div>
```

- **Last 10 sessions only** (D-11) — most recent first (descending by
  start time). No pagination control, no "view all" link this phase.
- **Multi-deck sessions** (D-09): render **one `Badge` per deck** studied
  in that session, `variant="secondary"` (identical visual token to the
  existing deck badge in the study header), wrapped with `flex-wrap` so a
  Global SR session spanning several decks doesn't force horizontal
  scroll or truncate silently. Deck titles are user content — render as
  plain text inside the badge, never translated (D-07-style precedent
  from `study.deckBadgeAriaLabel` / `DeckPickerItem`).
- **Abandoned/incomplete sessions** (D-08): shown in the list like any
  other row — **not** hidden, **not** in a separate section. Distinguished
  only by the "Incomplete" `Badge variant="outline"` appended after the
  duration value. Duration and card count for these rows reflect
  whatever partial progress was captured (elapsed time so far, cards
  reviewed before abandonment) — same columns, same formatting, no
  special-case layout.
- **Duration format:** mm:ss for durations under an hour (`formatDuration`
  — same mm:ss construction already used in `StudySessionPage.tsx`'s
  session-complete screen, lines 78–81: `Math.floor(elapsedSec / 60)` /
  `elapsedSec % 60`, zero-padded). This matches the session timer's
  mm:ss format (both represent whole-session durations, unlike the
  per-card flip-time column which uses decimal seconds).
- **Date format:** reuse whatever locale-aware date formatting utility
  already exists in the codebase for user-facing dates (if none exists,
  a simple `toLocaleDateString()` respecting `i18n.language` is
  sufficient — this is a mechanical detail for the planner, not a new
  design pattern).

## Accessibility Contracts

| Element | Requirement |
|---------|-------------|
| `SessionTimer` | `role="timer"`, `aria-live="off"` — identical contract to `ExamTimer.tsx`; the accessible name (`aria-label`) updates every second but is not announced automatically, preventing screen-reader spam during a long session |
| Recent Sessions table | `role="region"` + `aria-label` on the `overflow-x-auto` wrapper — same pattern as the existing per-deck table wrapper (`StatsSummaryPanel.tsx` line 127) |
| "Incomplete" badge | Text content ("Incomplete") is the accessible name — no additional `aria-label` needed, same as every other `Badge` usage in this file |
| Per-deck avg-flip-time cell | No additional `aria-label` needed — cell text ("3.4s" or "No data yet") is read directly by screen readers via standard table semantics, same as every other cell in this table |
| Multi-deck badges in a session row | Each `Badge` is a plain text node — screen readers read them in sequence as part of the row; no `aria-label` override needed since deck titles are meaningful text |
