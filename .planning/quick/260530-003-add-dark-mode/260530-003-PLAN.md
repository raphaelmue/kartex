# Quick Task 260530-003: Add Dark Mode

Wire up the dark mode toggle. Tailwind `darkMode: 'class'` and `.dark`
CSS variable block are already in place. Three files needed:

1. `ThemeContext.tsx` — provider + `useTheme` hook (stores preference in

2. `main.tsx` — wrap app in `<ThemeProvider>`
3. `AppShell.tsx` — add Moon/Sun icon button in the sidebar footer

No new packages — `lucide-react` is already installed.
