# Quick Task 260530-004: Add to Library

## Goal

Let any user add a PUBLIC deck to their library (study without forking).
Backend creates a READ DeckShare for the requesting user.
Frontend adds a "Library" button on each explore card alongside Fork.

## Tasks

### Task 1 — Backend: POST /api/decks/:id/library

**Files:** `apps/backend/src/routes/decks.ts`
**Action:** Append endpoint before the export. Upserts a READ DeckShare
for the calling user on a PUBLIC deck. Returns 409 if user owns the deck
or if deck is not public (403).

### Task 2 — Frontend: "Add to Library" button in ExplorePage

**Files:** `apps/frontend/src/pages/ExplorePage.tsx`
**Action:** Import `useAuth`, add `addingToLibraryId` state,
`handleAddToLibrary` fn (POST .../library, toast on success/409/error).
Add `BookMarked` button in CardFooter. Hide both buttons for own decks
(deck.ownerId === user.id).

## must_haves

- `POST /api/decks/:id/library` upserts READ DeckShare, returns 201
- Returns 409 when user is the deck owner
- Returns 403 when deck is not PUBLIC
- "Add to Library" button appears on all explore cards except own decks
- 409 from backend shows "Already in your library" toast (idempotent UX)
