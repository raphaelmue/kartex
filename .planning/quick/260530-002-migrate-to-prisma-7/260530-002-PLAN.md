# Quick Task 260530-002: Migrate to Prisma 7

## Goal

Upgrade `prisma` and `@prisma/client` from `^5.22.0` to `^7.0.0` in
`apps/backend/package.json`. Regenerate the Prisma client, verify the
TypeScript compilation is clean, and confirm the test suite still passes.

## Tasks

### Task 1 — Update package versions and install

**Files:** `apps/backend/package.json`
**Action:** Change `"prisma"` and `"@prisma/client"` from `"^5.22.0"` to `"^7.0.0"`.
Run `yarn install` from the repo root.
**Verify:** `yarn install` exits 0.
**Done:** `node_modules/@prisma/client/package.json` shows version 7.x.

### Task 2 — Regenerate Prisma client

**Files:** `apps/backend/prisma/schema.prisma` (read-only), generated client
**Action:** Run `yarn workspace @kartex/backend exec prisma generate`.
**Verify:** Command exits 0 with no errors.
**Done:** Generated client reflects Prisma 7 runtime.

### Task 3 — Verify types and tests

**Files:** All `apps/backend/src/**/*.ts`
**Action:**
1. Run `yarn workspace @kartex/backend run typecheck` — fix any type errors
   introduced by API changes in Prisma 7.
2. Run `yarn workspace @kartex/backend run test --run`.
**Verify:** Both commands exit 0.
**Done:** Zero type errors, all tests pass.

## must_haves

- `@prisma/client` version in package.json is `^7.0.0`
- `prisma generate` runs without errors
- `typecheck` exits 0
- `test` exits 0
