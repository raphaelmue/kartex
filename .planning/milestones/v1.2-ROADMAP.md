## Milestone Summary

**Key Decisions:**
- isActive stored on Deck model; studyMode stored on User model — single-table approach, no premature join tables
- SM-2 multiplier applied post-calculateSM2 as nextReviewAt post-processor — raw CardProgress.interval never modified
- Prisma migration SQL hand-written (prisma migrate dev unavailable); applied via Docker Compose entrypoint on deploy
- Typst WASM (28 MB) excluded from vite-plugin-pwa globPatterns via globIgnores; CacheFirst runtimeCaching rule for *.wasm
- VitePWA placed last in plugins array for WASM compatibility (Pitfall 6)
- maximumFileSizeToCacheInBytes set to 3 MiB — main bundle (2.16 MB) exceeds Workbox default 2 MiB limit
- COEP/COOP headers added as Hono global middleware step 0 — resolves pre-existing production gap
- sw.js served with Cache-Control: no-store via explicit Hono route before serveStatic catch-all

**Issues Resolved:**
- Pre-existing COEP/COOP gap in production (was dev-only via Vite server.headers) — fixed in Phase 12
- Hono server crash without DB connection at startup — seedAdminIfNeeded wrapped in try-catch (Phase 12 Plan 04)
- stale Nginx/pnpm references in docs/design.md — corrected in Phase 13

**Tech Debt Deferred:**
- Deck-specific /decks/:id/learn accessible for inactive decks — POST /api/study/rate returns 403 (UX dead-end; not a DECK-02 violation)
- Phase 10 VALIDATION.md status = draft (Nyquist compliance not updated after tests passed)
- DB migration hand-written — column existence in live DB not confirmed in CI
