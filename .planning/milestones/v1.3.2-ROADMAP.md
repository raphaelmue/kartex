**Status:** ✅ SHIPPED 2026-06-15

## Overview

Round off two UX rough edges, add a proper app logo, and give every shipped release a durable human-readable record. Users can now permanently remove public/shared decks from their library, the app logo is a new "K" on a learning-card motif SVG, CHANGELOG.md is backfilled for all past milestones, study cards show which deck they belong to, and the cross-deck shuffle is statistically verified.

## Milestone Summary

**Key Decisions:**

- DELETE /api/decks/:id/library uses compound unique key `{ deckId_sharedWithUserId }` — consistent with existing PATCH handler
- Logo SVG uses `<rect>/<polygon>` only — no `<text>` element (Docker/librsvg font safety)
- `apple-touch-icon.png` copied from `apple-touch-icon-180x180.png` (minimal-2023 preset does not generate it directly)
- Icons generated via `sharp@0.35.1` directly — nested `sharp@0.33.5` in @vite-pwa/assets-generator has DLL incompatibility on Windows x64
- Deck badge unconditional in progress row — not gated on studyMode
- STUDY-05 confirmed closed — Fisher-Yates does not produce deck-grouped output; no bug fix needed

**Issues Resolved:**

- @vite-pwa/assets-generator ERR_DLOPEN_FAILED on Windows x64 — bypassed with direct sharp@0.35.1 script
- Radix UI DropdownMenu 2.x requires `fireEvent.pointerDown` before `fireEvent.click` in JSDOM

- Zip file support for deck update via import (captured as todo 2026-06-15)
- Quick-edit / jump-to-card button in study mode (captured as todo 2026-06-15)
- de.json placeholder quality — needs native speaker review
