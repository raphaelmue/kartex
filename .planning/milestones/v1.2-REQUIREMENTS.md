All requirements satisfied at milestone close.

## User Stories & Acceptance Criteria

### Active Deck Management

- [x] **DECK-01**: User can mark a deck as active or inactive via a toggle on the deck list or deck detail page
- [x] **DECK-02**: The /study global session only queues due cards from decks the user has marked active
- [x] **DECK-03**: User can select which active decks to include in a /study session via a deck picker on the study start screen (active decks pre-checked; user can uncheck for this session only)
- [x] **DECK-04**: /study start screen has a session size picker (All / 10 / 20 / custom), matching the existing picker on /decks/:id/learn

### SM-2 Preset Modes

- [x] **SM2-01**: User can choose a study mode: Normal (default SM-2 intervals), Intensive (intervals × 0.5), or Exam Prep (intervals × 0.25)
- [x] **SM2-02**: Study mode is stored server-side per user and applied at the `POST /api/study/rate` endpoint — not client-side
- [x] **SM2-03**: `/settings` page shows a study mode selector (replaces the `<ComingSoon>` placeholder)
- [x] **SM2-04**: The SM-2 interval multiplier affects only `nextReviewAt` scheduling; the raw SM-2 interval stored in `CardProgress.interval` is never modified by the multiplier

### PWA Installable Shell

- [x] **PWA-01**: App has a web app manifest (name, icons 192×192 + 512×512, theme color, `display: standalone`) so browsers offer "Add to Home Screen"
- [x] **PWA-02**: Service worker pre-caches static JS/CSS/HTML for fast app shell load on repeat visits; Typst WASM files are excluded from precache (handled via network-first runtime caching)
- [x] **PWA-03**: All `/api/*` requests bypass the service worker (NetworkOnly strategy) — no card data or session state is cached by the SW
- [x] **PWA-04**: Production Hono server sets `Cross-Origin-Opener-Policy: same-origin` and `Cross-Origin-Embedder-Policy: require-corp` headers
- [x] **PWA-05**: `sw.js` and `workbox-*.js` are served with `Cache-Control: no-store` so redeployments propagate immediately

### Documentation

- [x] **DOCS-01**: `README.md` exists at the repository root with project overview, tech stack summary, Docker Compose quick-start, and links to `docs/design.md` and `docs/kartex-format.md`
- [x] **DOCS-02**: `docs/design.md` updated to remove Nginx/pnpm references; accurately reflects Hono `serveStatic` and yarn@4.15.0
- [x] **DOCS-03**: `docs/kartex-format.md` reviewed and accurate against the v1.1 parser implementation
