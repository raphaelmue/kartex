## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API response → client state | cards.tags[] strings are rendered into DOM via React JSX interpolation |
| User input → sessionSize | Custom number input accepts arbitrary integer values |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-03 | Tampering | Tag name rendered as chip text `{tag}` | accept | React JSX auto-escapes all string interpolation — `{tag}` in JSX produces text node, never raw HTML. No XSS surface. |
| T-08-04 | Tampering | Custom session size Input type="number" — NaN, negative, zero | mitigate | `Math.max(1, parseInt(e.target.value, 10) \|\| 1)` in onChange; NaN coerces to 1, values < 1 coerce to 1. Input type="number" + min={1} provides browser-level guard as first line. |
| T-08-05 | Denial of Service | Very large customCount (e.g. 999999) requesting slice | accept | Slice is client-side (`tagFiltered.slice(0, N)`); only operates on already-fetched cards array. No server call is made with the count. Maximum bound is naturally the fetched array length. |
| T-08-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed. Package legitimacy gate not applicable. |
</threat_model>
