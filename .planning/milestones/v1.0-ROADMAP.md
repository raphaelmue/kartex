# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-05-30
**Phases:** 1–6
**Total Plans:** 18

## Overview

Kartex v1.0 MVP — a fully self-hosted flashcard web application with SM-2 spaced repetition. Built from scratch in 5 days across 6 phases, shipping JWT auth, full deck/card CRUD, rich multimedia rendering (KaTeX, Typst WASM, images, audio, video, code), a spaced repetition study loop with dashboard, a `.kartex` import pipeline, deck sharing/forking, an /explore page, and a production Docker Compose stack with GitHub Actions CI.

## Milestone Summary

**Key Accomplishments:**
1. Fully deployable Docker Compose stack with JWT auth, invite codes, and admin panel shipped in Phase 1
2. Complete deck/card CRUD with Markdown rendering and tag support (Phase 2)
3. Rich multimedia rendering — KaTeX math, Typst WASM, images, audio, external video, syntax highlighting (Phase 3)
4. SM-2 spaced repetition engine with deck mode, exam mode, and dashboard with streak/stats (Phase 4)
5. `.kartex` import pipeline — YAML parser, zip bundle, 4-state preview UI, media extraction (Phase 5)
6. Deck sharing (READ/EDIT grants), /explore page, fork, GitHub Actions CI, production deploy (Phase 6)

**Key Decisions:**
- D-05: Removed Nginx from Docker Compose — Hono serves the built React SPA via `serveStatic` from `./public`
- D-06: Frontend built into `apps/backend/public/` by Dockerfile frontend-builder stage
- Typst WASM is a hard v1 requirement — loaded lazily via singleton
- Videos as external links only (YouTube/Vimeo iframes) — no self-hosted video storage
- SM-2 quality mapping: Again=0, Hard=3, Good=4, Easy=5
- react-markdown v10 requires custom `kartexUrlTransform` to pass `media://` through to component handlers

**Issues Resolved:**
- react-markdown v10 defaultUrlTransform strips unknown protocols — fixed with custom transform
- Vitest 4.x requires Vite ^6.0 — pinned vitest@2.1.9
- `vi.hoisted()` required for mock variables inside `vi.mock()` factory
- Prisma 7 removed `url` from datasource — requires `prisma.config.ts` + pg driver adapter
- Dockerfile missing `prisma.config.ts` copy — fixed in quick task 260530-005
- rehype-highlight adds `hljs-` prefix to language classes — fixed typst block detection

**Issues Deferred:**
- Add to Library for public decks on /explore (v1.1)
- Tag-based topic filter for study sessions (v1.1)
- i18n internationalization (v1.1)
- Prisma 7 WASM test failures for CARD-08 (Typst) — pre-existing, not introduced by this milestone

**Technical Debt Incurred:**
- VERIFICATION.md human tests were completed at milestone close, not inline with each phase
- Quick task SUMMARY.md files used prefixed names (`260526-001-SUMMARY.md`) instead of plain `SUMMARY.md` — requires rename for audit tool compatibility
